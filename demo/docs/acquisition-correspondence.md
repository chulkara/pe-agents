# Acquisition correspondence

The fixed-template form has been replaced by **local Qwen drafting**. See
[the current setup and review guide](local-outreach-pilot.md).

Confirm a real buyer introduction, select facts from a reviewed current call
brief, export the writing assignment, run it on your Mac and import result.json.
Review the prose, references and exact recipient before approval.

Internal notes are writing guidance, not facts and not email text. The model must
rewrite relevant notes using the selected evidence. There is no automatic canned
draft or hosted-model fallback when local generation fails.

Earlier drafts remain in preparation history and are marked for replacement in
the interface. Their wording is not silently rewritten. The original guide
described a template-only approach; it no longer describes the active workflow.
